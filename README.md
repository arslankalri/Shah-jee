# SHAH JEE — Restaurant Website

Bilingual (Japanese/English) static website for SHAH JEE in Ōhira, Miyagi. Built with HTML, CSS and vanilla JavaScript; no build step or API keys required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish

Import this repository into Vercel as a static site. No build command is required; the output directory is the repository root.

## Content accuracy and image policy

- Business name, address and phone are cross-checked against the restaurant's public Tabelog listing and JIMOHACK Miyagi coverage.
- Publicly documented dish examples include biryani, curry and naan. This is **not a complete or guaranteed current menu**. Prices are intentionally omitted; current availability should be confirmed with the restaurant.
- Third-party listings conflict on opening hours, so the site does not state a specific schedule.
- No stock food photography or copied Instagram images are used. The hero uses an original CSS ornament; visitors are linked to the restaurant's Instagram and public menu-photo gallery.
- Instagram: https://www.instagram.com/pakistan_restaurant_shahjee/
- Tabelog menu-photo gallery: https://tabelog.com/miyagi/A0403/A040304/4018614/dtlmenu/photo/
- JIMOHACK Miyagi (older article): https://jimohack.miyagi.jp/shah-jee/

Please have the restaurant owner review all content before treating this as its official website.
